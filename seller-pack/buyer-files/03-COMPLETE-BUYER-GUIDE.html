Complete Buyer Guide

This guide expands on 02-START-HERE.html with a full walkthrough of every configuration option in the Precision Laser Website Template.

1. Site architecture

The template is a single-page site (index.html) with anchored sections — Services, Materials, Gallery, Process, File Preparation, About, Service Areas, the Quote Planner, the Quote Form, FAQ, and Contact — plus four standalone pages: privacy.html, terms.html, disclaimer.html, and 404.html.

FilePurposeEdit for rebranding?
site-config.jsAll business content, contact details, services, materials, planner rates, themes, legal textYes — this is the file you edit
index.htmlPage structure/markupNo, not for ordinary rebranding
style.cssDesign system + 3 themesOnly if you want to change the visual design itself, beyond the built-in themes
app.jsRenders config-driven content, wires up navigation/formsNo
planner.jsPure calculation engine for the Quote PlannerNo, unless you are a developer changing the underlying formula

2. Rebranding your business identity

In site-config.js, edit the business object:

business: {
  name: "Your Business Name",
  logoText: "Your Business Name",
  logoMark: "[YBN]",
  tagline: "Your one-line tagline.",
  foundedYear: "2019",
  description: "A short paragraph about your real business."
}

Then edit contact for phone, WhatsApp, email and address; hours for your working hours; social for your social links; and serviceAreas for the list of areas you serve.

3. Configuring materials

Each entry in planner.materials looks like this:

"acrylic": {
  label: "Acrylic",
  icon: "🔷",
  description: "Cast and extruded acrylic sheet, clear and coloured.",
  rateMinPerCm2: 0.90,
  rateMaxPerCm2: 1.80,
  engraveRatePerCm2: 0.35
}

rateMinPerCm2 / rateMaxPerCm2 set the low/high price band per square centimetre of material processed (used for cutting). engraveRatePerCm2 is an additional per-square-centimetre surcharge applied when a job involves engraving. Add a new material by copying an existing entry and giving it a new key; remove one by deleting its entry (and its key from materialOrder).

4. Configuring services

The 7 services shown on the homepage (Laser Cutting, Laser Engraving, Signage, Acrylic Fabrication, Wood Engraving, Metal Marking, Corporate Gifts) live in the top-level services array, each with an id, icon, name, summary, details, and startingPrice string. Separately, planner.serviceTypes defines the service options offered inside the Quote Planner itself, each with a label and a defaultChecklist array shown in the results.

5. Quote Planner pricing logic (advanced)

The preliminary budget range is calculated as:

area(cm²) × material rate × thickness-band multiplier × cut-complexity multiplier × finish multiplier
  + (engraving area × material engrave rate, if engraving applies)
  × quantity
  + contingency % applied to the upper figure only
  → rounded to the nearest `roundTo` increment

You can tune every part of this from site-config.js:

Config keyControls
thicknessBandsMultiplier bands by material thickness (mm)
cutComplexityMultiplierMultiplier for simple outline / moderate detail / intricate detail / nested parts
finishMultiplierMultiplier for raw edge / polished edge / painted / assembled / packaged
contingencyPercentPercentage buffer added to the top of the range
roundToRounds the final min/max to the nearest multiple of this number
currency{ code, symbol, locale } — controls the currency symbol shown

6. Disabling price estimates

Set planner.budgetEnabled: false. Every other Planner output (scope, checklists, missing information, assumptions, next-step recommendation) keeps working; only the numeric budget range is hidden and replaced with a message pointing the visitor to contact you directly.

7. Themes

Three built-in themes are defined under themes in site-config.js: Graphite Laser (deep graphite/matte black with electric cyan and laser-red accents), Cyan Blueprint (deep navy blueprint tones with cyan and amber accents), and Amber Workshop (warm graphite/bronze tones with amber accents). Set activeTheme to the key of the theme you want as the default. Visitors can also switch themes live using the theme selector in the navigation bar; their choice is remembered in their browser.

8. FAQ, testimonials, and gallery content

The faqs array controls the FAQ accordion. The gallery array controls the project gallery — each entry ships with image: null, which renders a labelled placeholder card; set image to a real photo path once you have real project photography. This template intentionally does not include fabricated testimonials, ratings, or statistics — add your own only if you can back them with real, verifiable data.

9. Deployment options

Any static host works. A few common free/low-cost options:

  • GitHub Pages — push the folder to a GitHub repository and enable Pages in the repository settings.
  • Netlify / Vercel / Cloudflare Pages — drag-and-drop or connect a repository; each offers a generous free tier for static sites.
  • Traditional web hosting — upload the files via FTP/SFTP or your host's file manager.

None of these are included with your purchase — you will need to sign up for a hosting service and, separately, register a domain name if you want a custom web address instead of the host's default subdomain.

10. Troubleshooting

My changes to site-config.js aren't showing upHard-refresh your browser (the file may be cached), and confirm you saved the file and are viewing the deployed/served copy, not a stale local one
WhatsApp button doesn't open the right numberCheck contact.whatsappNumber is digits only, including country code, with no spaces or symbols
Budget range looks wrongDouble-check the material's rateMinPerCm2/rateMaxPerCm2 and your chosen roundTo/contingencyPercent — the calculation is deterministic from these inputs
Planner tests fail after I edited planner.jsRun npm test to see which specific assertion failed, and compare against the original file if you're unsure — most buyers never need to touch this file
