Thanks for downloading the Precision Laser Website Template. This page is your quick-start map — read this first before opening any other file.

What you purchased: a static HTML/CSS/JavaScript website template for laser cutting, engraving, signage, acrylic fabrication and small fabrication businesses, built around an interactive Laser Cut & Engraving Quote Planner. This is a digital download only — no physical item, no hosting, and no domain name are included.

What's in this ZIP

  • index.html — the site (all sections, single page)
  • style.css — the design system and 3 colour themes
  • site-config.js — edit this file to rebrand the site (see below)
  • planner.js / app.js — the Quote Planner logic and site interactivity (you generally never need to edit these)
  • privacy.html, terms.html, disclaimer.html, 404.html — legal/starter pages
  • favicon.svg, og-image.svg, robots.txt, sitemap.xml — SEO/social basics
  • package.json + tests/ — an optional test suite (38 automated tests) for the planner's calculations, useful if you or a developer modify planner.js

How to preview it locally

No build step is required. The simplest way to preview:

  1. Unzip this package into its own folder.
  2. Double-click index.html to open it directly in a browser, or for the most accurate preview, serve the folder with any static file server (for example, Python's built-in server: python3 -m http.server 8080, then visit http://localhost:8080).

How to change your business details

Open site-config.js in any text editor. Every business-identity field lives under the business, contact, hours, social, and serviceAreas sections at the top: name, tagline, phone, WhatsApp number, email, address, working hours, and social links. You should not need to touch index.html, style.css, app.js, or planner.js for ordinary rebranding.

How to configure your materials

The planner.materials object in site-config.js lists every material shown in the Materials section and offered in the Quote Planner. Each entry has a label, icon, description, and the three pricing fields explained below. Add, remove, rename, or reprice materials by editing this object — the Materials section on the page and the Planner's material dropdown both read from the same list automatically.

How to configure the Quote Planner

All Planner behaviour is controlled from the planner section of site-config.js:

  • materials — per-material rate range (rateMinPerCm2 / rateMaxPerCm2) and engraving surcharge (engraveRatePerCm2)
  • serviceTypes — each service's label and its default service checklist
  • cutComplexityMultiplier, finishMultiplier, thicknessBands — the multipliers that shape the budget range
  • filePrepChecklists — the checklist shown for each file-readiness answer
  • currency, contingencyPercent, roundTo — currency symbol/locale and how the final range is rounded

Every number in this section is a sample illustrative rate. Replace them with your own researched pricing before publishing your site.

How to disable price estimates

Set planner.budgetEnabled to false in site-config.js. The Planner will still produce the full scope, service checklist, file-preparation checklist, missing-information list, assumptions and next-step recommendation — it simply stops showing a numeric budget range, and shows a message directing the visitor to contact you for a custom quotation instead.

How to update WhatsApp

Edit contact.whatsappNumber (digits only, with country code, e.g. 27821234567) and contact.whatsappDisplay (the human-readable number shown on the page) in site-config.js. Every WhatsApp button on the site reads from these two fields.

How to update email

Edit contact.email in site-config.js. Every "Email Quote Request" action and mailto link on the site reads from this one field.

How to deploy

This is a static site — it can be hosted anywhere that serves plain HTML/CSS/JS files: GitHub Pages, Netlify, Vercel, Cloudflare Pages, or traditional shared hosting. Upload the contents of this folder (not the ZIP itself) to your host of choice. There is no server-side code and no database to configure.

What "hosting" and "domain" mean (if you're new to this)

Hosting is the service that actually serves your website files to visitors' browsers — this template does not include hosting; you'll need to choose and set up a host (many of the options above have free tiers). A domain name (like yourbusiness.com) is a separate purchase from a domain registrar that points visitors to your hosted site — this template does not include a domain.

What is NOT included

  • Hosting or a domain name
  • A backend server, database, or customer/order management system
  • Payment processing
  • Real business content — all names, contact details, and copy are fictional placeholders you must replace
  • Real project photography — the gallery ships with clearly labelled placeholder cards
  • Ongoing custom development or design work beyond the included template
