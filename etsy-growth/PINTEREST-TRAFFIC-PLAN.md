# Pinterest Traffic Plan — NextGenWebs → Etsy

**Goal:** Create the first durable **external** visit stream (currently Social = 0).  
**Rule:** Every pin that sells must link to an **exact Etsy product URL**, never the shop homepage alone.  
**Until URLs are pasted by human:** use demo/portfolio links for education pins; keep a private column `exact_etsy_url`.

---

## Why Pinterest first

- Template and “website inspiration” content has long shelf life  
- Buyers save planning pins before purchase  
- Fits static screenshots of UIs better than time-sensitive FB posts  

No volume guarantees.

## Pin formula

```
[Vertical] website template + [differentiator]
→ 1 practical sentence
→ Digital download note
→ Soft CTA: “Open listing / View template”
→ Exact product URL
```

### Example (L04)
**Title:** Tiling Contractor Website Template with Tile Calculator  
**Description:** Website template for tiling and flooring businesses with an interactive tile project planner. Preliminary estimates only. Digital download for contractors.  
**Link:** `EXACT_ETSY_PRODUCT_URL_L04`  
**Alt:** Screenshot of tiling website template tile calculator interface  

---

## Creative rules

1. Vertical 2:3 where possible  
2. Huge headline (buyer language)  
3. UI screenshot ≥40% of pin  
4. “Digital download” text on image  
5. No fake review stars  
6. No medical before/after for wellness/skincare  
7. One product per pin (avoid collage of whole shop)

## Measurement

| Metric | Weekly target style |
|---|---|
| Outbound clicks to Etsy | Any >0 is progress from baseline 0 social |
| Saves | Leading indicator |
| Etsy “Social media” visits | Must move off 0 |
| Saves→click rate | Improve creative if saves high clicks low |

---

## Do not

- Mass-post 100 near-identical pins in one hour  
- Use URL shorteners that break analytics  
- Pin to shop root as the only CTA for product content  
- Promise “this pin will rank #1”
