**Rules:** Benefit + product type · “Digital download” badge · no fake stars/bestsellers · no medical before/after  

Use **real product UI** screenshots when available. Placeholder: `REQUIRES_LIVE_SCREENSHOT`

## Thumbnail text hierarchy (all covers)

1. **What it is** (website template / dashboard / student lab)  
2. **Who it’s for** (one vertical)  
3. **Differentiator** (calculator / planner / CSV / Python)  
4. **Format** (digital download)  

## Production checklist

- [ ] Text ≥ 1/5 of cover height  
- [ ] Contrast AA-ish on overlay  
- [ ] No price on cover (price lives in Etsy UI)  
- [ ] No “#1 bestseller”  
- [ ] Screenshot is current live demo
