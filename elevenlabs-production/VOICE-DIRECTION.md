# Voice Direction — NextGenWebs ElevenLabs

## Primary voice profile

| Attribute | Direction |
|---|---|
| Gender presentation | Warm, clear, confident **male** voice |
| Accent | South African–friendly but **globally understandable** (light, not caricature) |
| Energy | Steady confidence; never shouty |
| Pace | Slightly measured; leave air for UI cuts (~140–160 wpm for shorts) |
| Tone | Useful, direct, slightly witty — not corporate, not fake hype |
| Sales posture | Soft authority — explain the value, don’t pressure |
| Forbidden | Movie-trailer grit, radio “hard sell,” robotic TTS cadence, whisper ASMR, celebrity impersonation |

## ElevenLabs settings (starting point — tune per voice)

| Setting | Guidance |
|---|---|
| Stability | Medium-high (less random drama) |
| Similarity / style | Moderate; avoid over-exaggeration |
| Speaker boost | On if available for clarity |
| Style exaggeration | Low |
| Speed | 0.95–1.05×; prefer natural |

Record **one approved “house voice”** ID in the private ops sheet (not in git if it reveals account details). Reference that voice for all queue rows marked `voice=nextgenwebs-house-male-v1`.

## Delivery rules for the speaker (or model prompt)

- Smile with the voice, not with fake excitement.  
- Emphasize **problem nouns** lightly: material, thickness, scope, CSV, quote.  
- Soften **disclaimers** but do not mumble them.  
- End CTAs cleanly; no “smash that like.”  
- No emojis spoken as words.  
- No “guaranteed leads,” “passive income,” or ranking promises.  

## Platform-specific delivery

| Platform | Adjust |
|---|---|
| Etsy 15s | Crisp; assume many viewers muted — VO still clear for those with sound |
| Shorts 20s | Hook in first 2 seconds; slightly faster |
| Reels 15s | Same as Shorts; tighter |
| Portfolio 45s | Warmer, more narrative; allow 1 short pause |
| Cold outreach note | Personal, slower, no broadcast energy |
| Blog summary | Podcast-calm; longer phrases OK |

## Negative prompts (for operators)

Do not use: celebrity names, politician voices, “sound like X,” cloned client voices without written permission, cartoon voices for professional products.

## QA checklist per take

- [ ] Intelligible on phone speaker  
- [ ] No clipped first/last word  
- [ ] No invented claims  
- [ ] Duration within ±15% of target  
- [ ] Filename matches queue  
- [ ] Export MP3 (or WAV master if preferred) without loudness wars
