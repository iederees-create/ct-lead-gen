### How the Surface Cleaning Estimate Planner Works
An 8-step wizard (Project Type → Measurements → Tile Details → Layout → Site Conditions → Wastage → Estimate → Send) that:
- Converts between metres, centimetres, feet, and inches, and supports single, multiple, wall, or floor-plus-wall measurement modes
- Calculates total area, wastage-adjusted coverage, tile count, and box count — always rounded up, never fractional
- Optionally estimates material cost and indicative adhesive/grout/levelling/waterproofing quantities (clearly labelled as non-binding guidance)
- Flags exactly what information is still missing for a firm quote
- Produces a structured project summary the visitor can copy, print, download, or send via WhatsApp or email — nothing is sent automatically
- Supports full keyboard navigation, screen readers, step indicators, inline validation, and an opt-in "save progress" toggle (off by default)

This tool gives **preliminary planning estimates only** — it is clearly disclaimed throughout as not a binding quote.
