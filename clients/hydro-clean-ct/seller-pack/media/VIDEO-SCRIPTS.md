# Hydro Clean video scripts

## Etsy listing video (50 seconds)
An exterior-cleaning website template should do more than display a phone number. Hydro Clean gives visitors a clear path from surface type and measurements to a structured request. Show the service sections, the responsive mobile layout, the planner, and the included buyer files. Everything is editable in one configuration file, so buyers can replace the sample business content with their own verified details. This is a digital template, not a hosted service, and it does not guarantee leads, rankings, sales, or quote conversion.

## Portfolio case study (75 seconds)
Many cleaning enquiries arrive without the measurements or access details needed for a useful reply. This project turns that vague first message into a structured brief. The planner collects surface, dimensions, condition, access, timing, and contact details, then offers WhatsApp, email, copy, and print handoff. It is responsive on desktop and mobile, configurable for a real business, and explicit that results are preliminary rather than binding quotes.
