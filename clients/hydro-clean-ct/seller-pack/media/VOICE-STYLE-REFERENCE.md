# NextGenWebs voice style reference

The workspace contains promotional scripts describing a calm, cinematic technology presentation: clear hooks, measured pacing, warm but restrained language, dark editorial visuals, clean sans-serif captions, and no copyrighted music. No reusable NextGenWebs voice ID or secret provider credential was found. ElevenLabs references are planning notes only.

Hydro Clean uses a neutral, trustworthy narration style at roughly 135–150 words per minute. Captions are sentence case, high-contrast, short lines, with a small disclaimer card at the end. Exports use MP4/H.264 with burned-in captions; audio-only deliverables use MP3 when a local voice engine is available.

This pack uses local Edge TTS when available. It does not use private RAVERSUS audio, private keys, or an external AI API.
