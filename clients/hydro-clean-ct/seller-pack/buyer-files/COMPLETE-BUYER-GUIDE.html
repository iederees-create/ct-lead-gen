Calculator disclaimer: The planner produces preliminary planning estimates only, not a binding quote. Material guidance coverage rates are indicative — always verify against your actual product's technical data sheet before configuring your own values. See legal.measurementDisclaimer in site-config.js and the Measurement & Estimate Disclaimer page.

If you have Node.js installed, you can verify the calculation engine after making changes: node tests/planner.test.js. All 31 tests should pass.

4. Deployment Instructions

Option A — GitHub Pages (free)

1. Create a new GitHub repository and upload all template files to it.
2. Go to Settings → Pages.
3. Under "Build and deployment", choose "Deploy from a branch".
4. Select branch "main" and folder "/ (root)", then Save.
5. Your site will be live at https://<your-username>.github.io/<repo-name>/

Option B — Any static host

Upload the folder as-is via FTP/SFTP, or drag-and-drop into Netlify/Vercel. No build step or server-side code is required.

Option C — Local preview only

Run python3 -m http.server 8000 from the folder and open http://localhost:8000/.
