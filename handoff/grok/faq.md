# FAQ — Southern Suburbs Builders Website Template

Use these in the Etsy listing FAQ module and buyer guide.  
Anything marked `VERIFY_AFTER_BUILD` must be confirmed before publish.

---

### 1. Is this a physical product?
No. This is a **100% digital download**. You receive downloadable website files. No physical item is shipped.

### 2. What makes this template different from a generic construction website?
The core differentiator is an interactive **Renovation Scope & Budget Planner**. Visitors can outline project **area**, **scope**, **complexity**, and **preliminary budget guidance**, then send a **structured quote request** instead of a vague one-line message. (`VERIFY_AFTER_BUILD` for final planner UX.)

### 3. Is the planner a real quotation tool?
No. It provides **preliminary, illustrative guidance only**. It is **not** a binding quotation, fixed price, formal tender, or professional cost estimate. You still inspect and price work using your own process.

### 4. Do I need coding experience?
For ordinary rebranding (business name, contact details, services, etc.), you should only need a text editor and the configuration file (`VERIFY_AFTER_BUILD` — expected `site-config.js`). Advanced layout or planner logic changes may require HTML/CSS/JS skills.

### 5. Is “Southern Suburbs Builders” a real company?
No. It is a **fictional demo business** used to showcase layout and features. All sample ratings, stats, testimonials, and project claims are placeholders to replace.

### 6. Can I use this for a client project?
Yes — typically under a **one end-business website** licence model. See `LICENSE.txt` in the package for exact terms (`VERIFY_AFTER_BUILD`).

### 7. Can I resell or redistribute the template?
No. You may not resell or redistribute the template itself as a template/theme. Running one business website (or one client website if the licence allows) is the intended use.

### 8. Where can I host the site?
Anywhere that serves static files — for example GitHub Pages, Netlify, Vercel, or conventional web hosting (`VERIFY_AFTER_BUILD` for any host-specific notes in the final package).

### 9. Does it include booking, payments, or a CRM?
No. The product focuses on presentation + planner + quote-request handoff (for example WhatsApp/contact links — `VERIFY_AFTER_BUILD`). It is not a booking system, payment processor, or CRM.

### 10. Does it work on mobile phones?
Yes — the template is intended to be **mobile-first and responsive** (`VERIFY_AFTER_BUILD` after breakpoint testing on the final build).

### 11. What files are included?
Website source files (HTML/CSS/JS), configuration for rebranding, the renovation planner, starter legal pages, and buyer documentation (`VERIFY_AFTER_BUILD` exact file list). Etsy packages are limited to a small number of download slots, so guides may be consolidated.

### 12. Are the Privacy Policy / Terms pages ready to publish as-is?
They are **generic starting points**, not legal advice. Have them reviewed for your jurisdiction before publishing.

### 13. Was AI used to create this product?
Yes. Site development workflows and commerce/listing materials were created with AI assistance (including Claude Code / Anthropic and Grok / xAI for commerce). See `AI-DISCLOSURE.txt` (`VERIFY_AFTER_BUILD`).

### 14. What is your refund policy?
As an instantly delivered digital product, refunds are handled **subject to Etsy’s digital-item policies and applicable consumer-protection law**. Refunds are generally considered only for a **genuine defect** in the template files, not for change of mind or dislike of fictional sample content.

### 15. What support is included?
Help with configuration questions and genuine template defects. Not included: custom development, full hosting/DNS setup, legal review, or construction estimating advice. Contact via Etsy Messages with your order number.

### 16. Can I change colours and branding?
Yes — theme/colour options and branding fields are intended to be buyer-editable via configuration (`VERIFY_AFTER_BUILD` for exact theme names and fields).

### 17. Can I change the budget logic or rates in the planner?
If the final build exposes assumptions/rates in config, you can tune them for your market (`VERIFY_AFTER_BUILD`). If logic is hard-coded, edits require JavaScript changes and are outside basic support.

### 18. Will this guarantee more leads or jobs?
No. A website template can improve presentation and enquiry quality, but results depend on your traffic, market, pricing, reputation, and follow-up. We do not promise lead volume or revenue.

### 19. Do I need WhatsApp?
WhatsApp handoff is a common path for this product line (`VERIFY_AFTER_BUILD`). You can still use phone/email CTAs if those are configured. Use a number you actively monitor.

### 20. What should I replace before going live?
All fictional contact details, sample ratings/stats, placeholder projects, and any claim you cannot substantiate (for example insurance, certifications, response times).
