# 7-Day Launch Campaign — Precision Laser Website Template

**Campaign narrative:** From vague laser enquiries to production-ready quote briefs.  
**Tone:** Direct, practical, sharp, slightly witty. Not corporate. Not desperate. Useful to laser businesses.  
**Sales path:** Attention → blog/project → demo → exact Etsy URL when public.  
**Forbidden claims:** Guaranteed leads, exact automated prices, bestseller status, fake urgency, medical lasers.

**Global placeholders:**  
`LIVE_DEMO_URL_PENDING_VERIFICATION` · `PORTFOLIO_PROJECT_URL_PENDING` · `EXACT_ETSY_PRODUCT_URL_PENDING_PUBLICATION` · `FINAL_SCREENSHOTS_PENDING` · `REQUIRES_FINAL_SCREENSHOT` · `CONFIRMED_PRICE_PENDING`

**Pre-publication default:** Days 1–6 can run education-first even before Etsy is public. Day 7 hard CTA only if exact product URL exists; otherwise soft “listing soon” + demo.
