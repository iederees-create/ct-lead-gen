## Checklist content (printable)

**Title:** Construction Quote Readiness Checklist  
**Subtitle:** What you need before a renovation or building price is meaningful

### Project basics
- [ ] Project type (reno / extension / new work / repair / multi-area)
- [ ] Suburb / service area
- [ ] Property type (house, flat, commercial unit, etc.)
- [ ] Occupied or vacant during works

### Size & drawings
- [ ] Approximate dimensions or room count
- [ ] Existing drawings / sketches available?
- [ ] Photos of current conditions (see photo list)

### Scope drivers
- [ ] Finish level (budget / standard / premium)
- [ ] Demolition extent
- [ ] Plumbing changes
- [ ] Electrical changes / capacity concerns
- [ ] Structural changes / openings
- [ ] Waterproofing needs
- [ ] Roofing involvement
- [ ] Flooring scope
- [ ] Painting / finishing scope

### Site & logistics
- [ ] Access / parking / carry distances
- [ ] Working-hour constraints
- [ ] Preferred timeline
- [ ] Target budget posture (range known / unknown)

### Compliance & visit
- [ ] Known approvals / HOA rules
- [ ] Site visit preferred dates
- [ ] Decision-maker contact details
- [ ] Additional notes / constraints

### Photo checklist (attach)
- [ ] Wide shot of each work area
- [ ] Problem details (damage, damp, cracks)
- [ ] Access path from street
- [ ] Electrical board (if relevant)
- [ ] Existing finishes to match/replace

**Footer note:** A structured website planner can collect many of these before WhatsApp. Online ranges remain preliminary — not binding quotations.
