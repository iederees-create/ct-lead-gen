# 7-Day Launch Campaign — Overview

**Narrative:** From vague enquiries to build-ready leads.  
**Tone:** Direct, practical, intelligent, slightly humorous, non-corporate.  
**Banned:** Fake scarcity · guaranteed leads/sales/estimates · bestseller claims  

Detailed day files: `DAY-01.md` … `DAY-07.md`  
Creative assets: `GROK-IMAGINE-PROMPTS.md` · `SHORT-VIDEO-SCRIPTS.md` · `CAROUSEL-COPY.md` · `STORY-COPY.md`  
Prior creative pack (preserve): `../campaign/`

---

## Day map

| Day | Hook | Main CTA | Pre-Etsy? | Real UI required? |
|---|---|---|---|---|
| 1 | This is not a quote request | Follow / education | **Yes** | No |
| 2 | Price means nothing without scope | Checklist education | **Yes** | No |
| 3 | Website qualifies the lead first | Live planner demo | **Yes** | `ACTUAL_PLANNER_SCREENSHOT` |
| 4 | Vague message → structured brief | Full live demo | **Yes** | Summary + mobile screenshots |
| 5 | Transparency builds trust | Explore full experience | **Yes** | Optional assumptions UI |
| 6 | More than a website | Template system / demo | **Yes** | Homepage, mobile, planner, themes |
| 7 | Quote request ready for review | Buy (gated) or demo | Demo always; Buy if URL live | Cover + homepage + planner + mobile |
