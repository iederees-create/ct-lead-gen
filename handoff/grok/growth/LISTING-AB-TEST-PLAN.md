# Listing A/B Test Plan

**Angles:**  
A — Better quote requests  
B — Interactive builder website  
C — Construction lead-qualification system  

**Rules:** No fabricated benchmarks. Observe before declaring winners. One change at a time when possible.

---

## Shared observation defaults

| Default | Value |
|---|---|
| Observation period | 14–28 days per test (or ≥100 visits if traffic allows) |
| Decision rule | Prefer higher conversion rate with stable refund/support load; if traffic thin, pick directional + qualitative |
| Confounders | Seasonality, price changes, new images, external shares, Etsy search rank shifts |

---
