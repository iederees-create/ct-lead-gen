# Video Storyboard — Southern Suburbs Builders Website Template

**Rules:** Use real finished-site UI only. No fake project photography. No guarantee claims. Always frame budget output as preliminary. Capture after build confirmation (`VERIFY_AFTER_BUILD`).

## A) Etsy listing video — 15 seconds

| Spec | Value |
|---|---|
| Length | ≤ 15 seconds |
| Audio | Silent (text/UI only; Etsy-friendly) |
| Aspect | Square 1:1 preferred (or vertical if encoding pipeline prefers; verify current Etsy guidance) |
| Codec | MP4 / H.264 |
| Size | Under 100MB |
| Source | Screen capture + light kinetic text overlays |

### Beat sheet (15s)

| Time | Visual | On-screen text |
|---|---|---|
| 0.0–2.0s | Cover / logo lockup on homepage hero | Construction Website Template |
| 2.0–5.0s | Scroll or cut to Renovation Planner entry | Renovation Scope & Budget Planner |
| 5.0–8.5s | Planner interaction: choose area / scope | Area · Scope · Complexity |
| 8.5–11.5s | Budget guidance panel with disclaimer visible | Preliminary budget guidance — not a binding quote |
| 11.5–13.5s | Structured quote / WhatsApp handoff CTA | Structured quote request |
| 13.5–15.0s | End card: template name + “Digital download” | Builder & contractor website template |

### Etsy video production notes

- Prefer cursor-visible interactions for planner credibility.  
- Keep text large (mobile feed legibility).  
- Do not show real client WhatsApp threads.  
- End card must not invent star ratings or “guaranteed results”.

### Beat sheet (≈40s target)

| Time | Visual | Voiceover / captions (safe copy) |
|---|---|---|
| 0–4s | Portfolio title card | Southern Suburbs Builders Website Template — construction lead site with a renovation planner |
| 4–10s | Desktop homepage tour | A responsive template for builders and renovation contractors |
| 10–18s | Open planner; step through area + scope | Visitors outline project area and scope instead of sending a one-line “how much?” message |
| 18–26s | Complexity + budget guidance | They receive preliminary complexity and budget guidance — clearly non-binding |
| 26–34s | Quote summary → WhatsApp/contact handoff | Then send a structured quote request the business can action |

> This template turns renovation interest into clearer enquiries. Homeowners walk through a Scope & Budget Planner for preliminary area, scope, complexity, and budget guidance, then submit a structured quote request. The planner is not a binding quotation. Built as a static, buyer-editable construction website template.
