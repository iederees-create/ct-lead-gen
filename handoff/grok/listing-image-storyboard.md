# Listing Image Storyboard — Southern Suburbs Builders Website Template

**Format:** 10 square images (preferred **2000×2000 PNG**)  
**Source rule:** Real UI screenshots / clean product graphics of the finished template only.  
**Do not:** invent fake renovation project photographs, stock “before/after” homes presented as real work, competitor screenshots, or unsupported claim badges (“4.9 stars”, “fully insured”, “200+ jobs”) unless clearly labelled as editable sample UI and not as proof.

**Status:** Storyboard only — capture after final build (`VERIFY_AFTER_BUILD` for every frame’s actual UI).

---

## Global art direction

| Element | Guidance |
|---|---|
| Aspect | 1:1 square |
| Background | Neutral dark or soft warm gray construction-adjacent palette (match final theme) |
| Typography overlays | Short benefit lines; no guarantee language |
| Device frames | Optional simple browser/phone chrome; keep legible |
| Watermark | Optional subtle “Digital Download” on cover only |
| Demo data | Fictional business name OK if clearly a template demo |
