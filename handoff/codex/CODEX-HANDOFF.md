## Validation Scripts

- `validate-tags.mjs`: validates exactly 13 unique Etsy tags, each <=20 characters, and rejects generic Etsy shop product URLs.
- `validate-product-pack.mjs`: validates manifest, safe paths, buyer files, listing images, symlink bans, missing references, secrets, and pack exclusions.
- `scan-secrets.mjs`: scans text files for common credentials, cookies, API keys, tokens, and private keys.
- `validate-media.mjs`: validates media signatures and uses `ffprobe` for video when available.
- `validate-links.mjs`: scans HTML/manifest links for unsafe local paths, malformed WhatsApp/mailto links, generic Etsy shop URLs, and missing local references.
- `validate-build-output.mjs`: checks build output for required entry files and forbidden release artifacts.
